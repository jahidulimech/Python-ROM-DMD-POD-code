The ROM workflow uses flow-field snapshots generated from an OpenFOAM
simulation. The OpenFOAM case itself is not included in this repository;
only the Python-based data processing, POD/DMD, shock tracking, and
reduced-order modeling scripts are provided.

The repository is intended to demonstrate the ROM methodology and
post-processing workflow rather than reproduce the full OpenFOAM case.
